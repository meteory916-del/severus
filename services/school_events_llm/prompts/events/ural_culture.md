## Событие: История и культура Урала
- **Смысл:** интерес к своему краю, культура и история Урала по проверенным источникам.
- **Желательные акценты:** конкретные места, ремёсла, литература, люди - по источникам; уважение к разным культурам региона.
- **Нежелательно:** обобщения о народах, выдуманные «уральские традиции», неподтверждённые факты.
- **Возрастная адаптация:** 1–4: сказы и ремёсла через творчество; 5–8: исследование по источникам; 9–11: краеведческий проект.
- **Идеи активностей (не шаблон, а ориентир):** работа с источниками, мастерская ремёсел, краеведческий маршрут по фрагментам.
- **Проверка содержания:** тематическое событие без официальной даты; все сведения - только по справочным фрагментам.
