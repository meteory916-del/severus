## Текущий этап: концепции вариантов (variation_plan)

Придумай ровно столько концепций, сколько указано в «Количество вариантов». Каждая концепция - основа самостоятельного полноценного сценария при тех же условиях.

Требования:
- Концепции различаются **механикой**, а не названием: разный `primary_mechanic`, разные ведущие типы активностей (`activity_type`), разный итоговый результат. Перефразирование одной идеи - ошибка.
- Все концепции соблюдают одни и те же условия: возраст, точное число детей и взрослых, длительность, формат, ресурсы, правила участия родителей.
- Для каждой ценности события укажи, какой механикой её реализует концепция (`values_to_mechanics`). Механики реализации ценностей у разных концепций тоже должны отличаться хотя бы в одной ценности.
- `planned_structure` - черновик блоков: 3–7 блоков для 30–45 минут, 4–9 для 60–90 минут; сумма `approx_minutes` примерно равна длительности.
- `differs_from` - для каждой другой концепции одно предложение: чем по сути отличается. При одном варианте - пустой массив.
- Если запрещены обязательные малые группы, `engagement_mode` не может быть `small_groups`.
