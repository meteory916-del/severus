# Каталог школьных событий Свердловской области (v2.6)

Единый каталог событий проекта. Его читают общий бэкенд (`backend/`) и LLM-сервис (`services/school_events_llm/`). Других копий каталога в репозитории нет.

**Правило одно: карточка лежит в `events/` - событие есть везде.** Бэкенд отдаёт его фронтенду, генератор принимает запросы по нему и собирает промпт. Чтобы убрать событие, карточку удаляют (или переносят из `events/`). Чтобы добавить - кладут карточку и блок генератора `services/school_events_llm/prompts/events/<id>.md`; без блока сервис не запустится и сообщит об этом.

## Структура

| Путь | Что это | Правится |
|---|---|---|
| `events/<id>.json` | карточка события - **источник истины** | руками |
| `sources/<id>.json` | источники события (`sources`) и фрагменты-цитаты (`fragments`) | руками |
| `regions/RU-SVE/metadata.json` | сведения о регионе | руками |
| `catalog_schema.json` | схема карточки | руками |
| `sources_schema.json` | схема файла источников | руками |
| `editorial/RULES.md` | правила подготовки содержания и приёмки | руками |
| `events_catalog_RU-SVE.json` | сводный JSON | только скриптом |
| `catalog_index.csv` | сводная таблица | только скриптом |
| `tools/build_catalog_index.py` | проверка и сборка производных файлов | - |

## Проверка и сборка

Из корня репозитория:

```bash
python catalog/tools/build_catalog_index.py           # проверить и пересобрать сводные файлы
python catalog/tools/build_catalog_index.py --check   # только проверить
```

Скрипт проверяет карточки и файлы источников по схемам, ссылки `source_ids`, фрагменты и наличие возрастного совета для каждой поддерживаемой группы. После любой правки карточки или источников его нужно запустить, иначе сводные файлы устареют.

## Карточка события

| Поле | Кто использует | Смысл |
|---|---|---|
| `id`, `title`, `aliases`, `category`, `supported_age_groups`, `supported_formats`, `catalog_version` | бэкенд, фронтенд, генератор | **названия и типы не менять**: на них завязан ответ `GET /api/v1/catalog/events` |
| `date_rule` | генератор | дата или правило даты |
| `educational_goals` | генератор | 1-3 воспитательные задачи |
| `values` | генератор | 1-3 ценности: `family`, `mutual_aid`, `historical_memory`, `labour_creation`, `cultural_diversity`, `citizenship` |
| `age_appropriateness_notes` | генератор | совет по каждой возрастной группе: формы работы и ограничения; в промпт попадает только нужная группа |
| `facts_to_verify` | генератор | что нельзя утверждать без проверенного фрагмента и где нужна осторожность |
| `regional_topics` | генератор | региональные темы вида `RU-SVE/<тема>` |
| `source_collection`, `source_ids` | куратор, генератор | файл и записи источников |
| `review`, `regional_variants`, `updated_at` | куратор | флаги проверки, регион, дата правки |

Смысл события для сценария (акценты, что нежелательно, идеи активностей) описан в блоках генератора `services/school_events_llm/prompts/events/<id>.md`. Генератор собирает промпт сам: блок события плюс данные карточки. Готовые промпты в каталоге не хранятся.

## Источники и фрагменты

- `sources` - записи об источниках с аудитом: ссылка, издатель, статус проверки, краткое описание (`text_excerpt` - описание, не цитата).
- `fragments` - точные цитаты из источников. Модель получает **только** фрагменты со статусом `verified`. Проверять фрагмент должен другой человек, не тот, кто его собрал (`verified_by` ≠ `collected_by`).
- Фрагменты со статусом `draft` - черновики, в генерацию не попадают.

Подробные правила - в `editorial/RULES.md`.

## Статус приёмки

Каталог не принят окончательно: у большинства событий не набран минимум проверенных источников (3 на событие, 10 на День Победы), независимая экспертиза не проводилась. Актуальные счётчики - в `catalog_index.csv`. Аудиторские таблицы лежат в `acceptance/`.

## История

- **v1.1-v2.5** (2026-10-18 - 2026-10-21): структура каталога, аудит источников, возрастная проверка, две региональные карточки-кандидата. Отчёты `ACCEPTANCE_REPORT_*` и `ACCEPTANCE_FOLLOWUP_*`, на которые ссылались прежние версии README, в репозиторий не добавлены; в репозитории есть таблицы из `acceptance/`.
- **v2.6** (2026-10-26): каталог стал единственным для бэкенда и генератора.
  - В карточки добавлены `values`, `regional_topics`, `facts_to_verify`; поле `prompt_block` удалено.
  - Возрастные советы сведены в одно поле: карточка, раздел промпта каталога и блок генератора.
  - Данные из `prompts/events/<id>.md` перенесены в карточки, общие правила - в `editorial/RULES.md`; папка `prompts/events/` удалена.
  - `regions/RU-SVE/verified_sources.json` удалён: 4 записи перенесены в `sources/` (`src_victory_day_001`, `src_victory_day_002`, `src_teachers_day_001`, `src_knowledge_day_004`); 5 записей повторяли ссылки, уже имеющиеся в `sources/`; 1 запись о регионе дублировала `metadata.json`.
  - Добавлены 38 черновых фрагментов-цитат (статус `draft`) из проверенных источников. Цитаты выписаны автоматически и короткие (до 125 знаков); их нужно сверить со страницами и подтвердить.
  - Новый год: категория `calendar` заменена на `school`.
  - День образования Свердловской области и День народов Среднего Урала доступны наравне с остальными. Проверенных фрагментов по ним пока нет, поэтому генератор строит сценарии без фактических утверждений о регионе.
  - Сводный JSON и CSV собираются скриптом `tools/build_catalog_index.py`.
  - Длинные тире в текстах карточек заменены на дефисы.
