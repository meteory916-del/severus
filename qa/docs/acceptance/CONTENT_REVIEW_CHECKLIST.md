# Чек-лист содержательной проверки сценария

Для экспертной проверки одного сценария. Ответы: «да», «нет», «частично». Если раздел неприменим, используйте «н/п».

Формальные проверки — сумма времени, доступность ресурсов, число участников и групп, лимит родителей — выполняются автоматически. Эксперт не пересчитывает их вручную, а оценивает педагогический смысл и качество предложенных решений.

Перед проверкой фактов уточните статус источников: в генерацию должны попадать только `verified`-фрагменты. Любой не-`verified` статус (`draft`, `pending`, `needs_content_review`, `rejected`) не подтверждает утверждение. Актуальный статус показывает `python -m app sources-check`.

**Сценарий:** ____________________  
**Ревьюер:** ____________________  
**Дата:** ____________________

Заполнение чек-листа QA-специалистом — предварительное. В Sprint 2 вердикт ставит ревьюер из команды: лид или QA. Смысловая оценка уходит учителю на демо и в проде — отдельного методиста в команде нет. Профильный эксперт по фактам и региону нужен только тогда, когда такие утверждения появляются в сценарии. Пример заполнения — `qa/docs/review/SCENARIO_REVIEW.md`.
