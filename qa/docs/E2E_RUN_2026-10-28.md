# E2E-прогон 28.10.2026

Цель: проверить единый путь «Frontend-контракт → Backend → LLM-сервис → ответ» в API-режиме, без демо-mock. UI-часть проверяется отдельно Олей; здесь — серверный путь и контракты.

## Стенд

- Backend: `GENERATOR_MODE=llm_service`, `http://127.0.0.1:8000`.
- LLM-сервис: `LLM_SERVICE_FIXTURE_MODE=true`, `http://127.0.0.1:8090`.
- Реальная модель недоступна: ключей `LITELLM_*` / `GIGACHAT_*` в окружении нет.
- Вместо модели — подготовленные ответы (`examples/golden`), как разрешено в задачах Sprint 2.

Обход ограничения fixture: сервис запускался с `LLM_SERVICE_FIXTURES=<один golden>`, чтобы эталон соответствовал событию запроса. Без этого HTTP-клиент всегда берёт первый эталон (BUG-04).

## Не выполнено и почему

| Что | Почему | Что снимет блокер |
|---|---|---|
| E2E-04…E2E-11 (8 кейсов) | Нет подготовленных ответов под эти события, возрасты и форматы; fixture не генерирует произвольный сценарий | Реальная LLM или набор эталонов под каждый кейс |
| UI-путь: выбор события → параметры → генерация → проект | Нет браузерной автоматизации; UI проверяет Оля | Ручной прогон Оли или Playwright |
| Отображение `partial` | Фронтенд не обрабатывает `partial` (BUG-01), проверка упрётся в известный дефект | Фикс `frontend/src/api.ts` |
| Отображение причины `failed` | API не отдаёт причину (BUG-02) | Фикс контракта/фронта |
| Качество реальной генерации | Fixture не является моделью | Доступ к провайдеру |

## Вывод

Серверная связка рабочая: контракт 01 проходит без преобразований, контракт 02 возвращается, тайминг и `quality_report` корректны, ошибки типизированы. Полный E2E на всех 12 кейсах и на UI **сегодня невозможен** из-за отсутствия модели и браузерной автоматизации, а не из-за дефекта интеграции.

Для Sprint 2 этого достаточно, чтобы закрыть задачу «сквозное тестирование» в доступном объёме: путь проверен, баг-лист собран, границы честно зафиксированы.

## Воспроизведение

```powershell
# Backend
$env:GENERATOR_MODE="llm_service"
python -m uvicorn backend.main:app --port 8000

# LLM-сервис с эталоном под событие
cd services/school_events_llm
$env:LLM_SERVICE_FIXTURE_MODE="true"
$env:LLM_SERVICE_FIXTURES="C:\GitHub\severus\services\school_events_llm\examples\golden\ex2_mothers_day.json"
python -m app serve --port 8090

# Запрос
python -m app generate examples/requests/ex2_mothers_day.json
```

Для 12 кейсов: `python qa/tests/e2e/run_e2e.py` (нужен живой провайдер либо эталоны под каждый кейс).
