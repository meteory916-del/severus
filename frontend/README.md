# Северус — фронтенд Sprint 1

React + TypeScript + Vite. Приветственная страница с фирменным логотипом, конструктор мероприятия, ожидание с анимацией и просмотр нескольких вариантов сценария.

## Установка

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.

## Два режима

- **Демо** (по умолчанию): локальный сценарий; работает без сервера. Демо-каталог содержит условное событие «День учителя» и **не отражает автоматически** актуальный каталог бэкенда.
- **API**: на странице конструктора выберите `API`. Каталог и ограничения будут загружены с `GET /api/v1/catalog/events`, `GET /api/v1/catalog/options`. Генерация отправляется через `POST /api/v1/generations`, далее опрашивается статус и загружается проект.

Для локального бэкенда из корня основного репозитория:

```bash
python -m pip install -r requirements.txt
python -m uvicorn backend.main:app --reload --port 8000
```

При необходимости задайте адрес сервера в `.env.local`:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Встраивание в основной репозиторий

Скопируйте папку `severus_frontend` в корень репозитория и переименуйте её в `frontend`. Не перезаписывайте каталоги backend, catalog, docs, tests. Файлы `node_modules` и `dist` добавьте в `.gitignore`.

## Что готово

- Авторский дизайн: светлая середина, тёмно-синие и зелёные боковые поля, золотые орнаменты, звезда и загруженный логотип.
- Анимация палочки и лани на стадии генерации; графика взята из пользовательского изображения.
- Реальный контракт запроса API, в том числе родительское участие и другие настройки.
- Синхронизация доступных форматов/возрастов с каталогом после подключения API.
- Отдельный тестовый режим без выдачи демо-результата за реальный ответ LLM.
- Обработка HTTP/сетевых ошибок, ограничения формы, визуализация вариантов, этапов, ролей, материалов и предупреждений.

Важно: API Sprint 1 использует mock-генератор и временную память. Результаты исчезают после рестарта сервера. Для долгосрочного сохранения и реальной LLM потребуются изменения бэкенда.

## Версия оформления по утверждённому макету (22.10.2026)

В этой версии обновлён визуальный стиль всех четырёх состояний: приветствие, конструктор, генерация, результат. Сохранены функции форм, локального демо и API. Изменена анимация: показана **только волшебная палочка с изумрудными волнами**, без лани. В шапке и подвале отображаются декоративные изумрудные камни, края страниц выполнены в сине-изумрудном оформлении. Скриншоты-референсы в качестве декоративных «плиток» больше не используются.

### Запуск на Windows в VS Code

1. Распакуйте архив. Откройте в VS Code папку, в которой расположен `package.json`.
2. Откройте **Terminal → New Terminal**, выполните:

```powershell
npm install
npm run dev
```

3. Откройте URL, показанный Vite в терминале (обычно `http://localhost:5173`).
4. Для проверки без сервера выберите **Демо**. Для подключения к Python-бэкенду выберите **API** и настройте URL в `.env` на основании `.env.example`.
5. Чтобы остановить Vite, в активном терминале нажмите `Ctrl+C`.

### Добавление в исходный GitHub-репозиторий команды

В корне локального клона `yasinnsbts/severus` создайте ветку, например `feature/frontend`. Скопируйте **содержимое этой папки** в `severus/frontend/` (то есть `severus/frontend/package.json` и `severus/frontend/src/`). Не копируйте `node_modules`, `dist`, `.env` с секретами. После проверки `npm run build` выполните `git add frontend`, создайте коммит, отправьте ветку и оформите Pull Request. Существующую папку `backend/` менять не нужно.

**Примечание:** это работающий по структуре исходный React/Vite-проект, однако в среде подготовки архива установка npm-зависимостей не завершилась, поэтому локальную сборку нужно подтвердить командой `npm run build`.

## Обновление Liquid Glass (v7)

В этой версии сохранены прежние боковые тёмно-синие декоративные панели с золотыми ветками, звёздами и полумесяцами. Обновлены только центральные карточки: полупрозрачное стекло, золотисто-бирюзовая окантовка, более чёткие отдельные карточки материалов и участников. На странице результата добавлен малоконтрастный SVG-силуэт лани `public/assets/doe-watermark.svg`. Подзаголовки «Слова и действия педагога» и «Что делают ученики» увеличены отдельно от основного текста.

Проверка: `npm install` и `npm run build` в каталоге `frontend`. В среде создания архива npm-зависимости не были доступны офлайн; локальная сборка не подтверждена.


## Версия с оформлением Liquid Glass
Сохранены четыре состояния интерфейса: приветствие, конструктор, загрузка и результат. Синий с золотом олень — декоративный неподвижный фон, остающийся за полупрозрачными карточками. В демо-режиме бэкенд не требуется, а для настоящих запросов включите режим API.

Для проверки перед Pull Request: `npm install`, `npm run build`, `npm run dev`. Не добавляйте `node_modules` и `dist` в Git.

## Утверждённый дизайн / локальная проверка

Эта версия включает приветственную страницу, конструктор, анимацию генерации
и экран результата. По умолчанию используется **Демо**: запросы в LLM не отправляются,
результат создаётся локальным генератором. Для реального API включите режим API
при запущенном бэкенде. Точный адрес сервера задаётся в `.env` по примеру `.env.example`.

### Windows / VS Code
1. Откройте в VS Code именно папку `frontend` (с `package.json`).
2. В терминале: `npm install`, затем `npm run dev`.
3. Откройте адрес, который выводит Vite (часто http://localhost:5173/).
4. Проверьте главную страницу, форму, анимацию и вкладки результата.
5. Выполните `npm run build` до создания Pull Request.

### Добавление в основной GitHub-репозиторий
В отдельной ветке основного репозитория `yasinnsbts/severus` поместите
содержимое этой папки в `frontend/`. Не копируйте `node_modules/` и `dist/`.
После проверки выполните `git add frontend`, `git commit`, `git push` и
откройте Pull Request в `main`. Не заменяйте папку `backend`.

## Доработки оформления (версия 13)
- Возвращено анимированное изумрудное свечение основных заголовков (при выключенном в системе режиме уменьшения движения).
- Сине-золотая лань размещается неподвижно в области экрана и целиком масштабируется через `background-size: contain`.
- Вокруг лани добавлены отдельные SVG-ветви, золотые звёзды и полумесяц, без вставки фрагментов скриншотов.
- Цветные и нейтральные информационные карточки получили более прозрачный фон, чтобы через них был виден задний план.
- Значения форм и подписи полей остаются без анимации для читаемости.
